# Flipper Zero BadUSB

Collection of BadUSB (DuckyScript) payloads for [Flipper Zero](https://flipperzero.one/).

## Use it on your Flipper

The **`badusb/`** folder is laid out for the Flipper SD card. Copy it so scripts live at:

```text
SD Card/badusb/Prank/...
```

Full install + run steps: **[badusb/README.md](badusb/README.md)**

Quick path with qFlipper:

1. Connect Flipper → open qFlipper File manager → `SD Card/badusb/`
2. Upload the folders from this repo’s `badusb/Prank/`
3. On device: **Bad USB → Prank →** pick a script → USB mode → plug into PC → **Run**

## Payloads

| Path | Description |
| --- | --- |
| `badusb/Prank/High_Contrast` | Toggle Windows high contrast |
| `badusb/Prank/Mouse_Zap` | Swap mouse button + slow cursor |
| `badusb/Prank/Nope_Pad` | Disable / restore laptop touchpad |
| `badusb/Prank/Telnet_Star_Wars` | Telnet ASCII Star Wars |
| `badusb/Prank/Win_Zoom` | Zoom Windows display |

The older `Prank/` tree is the original source layout (folder names with spaces). Prefer **`badusb/`** for device installs.
